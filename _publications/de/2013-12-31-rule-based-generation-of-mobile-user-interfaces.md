Die Beliebtheit mobiler Anwendungsplattformen wie iOS, Android oder Windows Phone 7 nimmt von Tag zu Tag zu. Die zugehörigen App-Stores bieten tausende unterschiedliche Anwendungen (sogenannte Apps) für nahezu jeden denkbaren Zweck. Aus Sicht der Softwareentwicklung bergen diese App-Stores ein hohes Potenzial: Entwicklerinnen und Entwickler erreichen die breite Öffentlichkeit und damit ein deutlich größeres Publikum als über jeden anderen Vertriebskanal. Mit der steigenden Zahl potenzieller Kundinnen und Kunden wachsen jedoch auch die Erwartungen an die User Experience. Der Benutzeroberfläche als zentralem Interaktionspunkt in mobilen Umgebungen kommt dadurch wesentlich mehr Aufmerksamkeit zu; Erfolg oder Misserfolg einer App hängen häufig von ihr ab. Darüber hinaus erwarten Benutzerinnen und Benutzer auf unterschiedlichen Plattformen dieselbe Bedienerfahrung. Um eine hohe Qualität in der Entwicklung von Benutzeroberflächen sowie die Entwicklung für verschiedene Plattformen zu ermöglichen, wird ein Framework vorgestellt, das eine plattformunabhängige Definition einer Benutzeroberfläche bietet, die durch Einschränkungen in Form von Regeln abgesichert ist. Mittels modellgetriebener Entwicklung erlaubt das Framework die Erstellung von Benutzeroberflächen, die nicht an eine bestimmte Zieltechnologie gebunden sind. Zudem ermöglicht es, eine Benutzeroberfläche zu definieren und sie unter Berücksichtigung vorgegebener Regeln in eine Zieloberfläche zu transformieren, sei es für Android, iPhone oder Windows Phone 7.
